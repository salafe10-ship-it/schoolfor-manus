# ADR-001: Student Admission Bounded Context

## Status
Approved

## Context
The system requires a robust, compliant, and multi-tenant student admission process.

## Decision
The Student Admission module will be implemented as an independent Bounded Context following Clean Architecture.
- Bounded Context: Student Admission
- Communication: Commands/Queries via Application Services, Events for Enrollment confirmation.
- Persistence: Postgres with RLS enforced.

## Consequences
- Positive: Improved maintainability, strict tenant isolation.
- Negative: Requires formal API contract definition for cross-context communication.

## Traceability
- Linked to: EBRC (Admission Rules), Enterprise Capability Map.
