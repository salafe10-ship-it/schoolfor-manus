# Examination Domain Map

- **Planning**: Academic Year, Semester, Subject Planning.
- **Scheduling**: Dates, Times, Venues, Proctors.
- **Question Management**: Question Bank, Question Types, Marks.
- **Sessions**: Student Attendance, Proctoring.
- **Marks**: Entry, Validation, Moderation.
- **Results**: GPA, Final Grades, Transcripts.
- **Archive**: Historical records.
