# بيئة اختبار شؤون الطلاب — استنفاد Supabase

## الهدف

بيئة محلية معزولة لاختبار سلوك وحدة شؤون الطلاب عندما تصبح قاعدة بيانات Supabase أو مواردها غير متاحة. المحاكاة لا تتصل بـ Supabase ولا تنفذ أي كتابة على بيانات مدرسة.

## التشغيل

```powershell
pnpm run test:student-affairs:exhausted
```

تفتح البيئة على:

`http://127.0.0.1:4180/?school=school_1`

بيانات الدخول المحلية:

- اسم المستخدم: `student-affairs-test`
- كلمة المرور: `student-affairs-test-password`

## السيناريو المحاكى

- الحالة: `503 Service Unavailable`
- الرمز: `TEST_SUPABASE_DATABASE_EXHAUSTED`
- المسارات: قراءة الطلاب، مؤشرات شؤون الطلاب، والسياق الأكاديمي.
- الاستجابة قابلة لإعادة المحاولة.
- `schoolDataTouched=false` في كل استجابة محاكاة.
- لا تُحمّل قيم `SUPABASE_URL` أو مفاتيح Supabase أو عناوين PostgreSQL.
- الخادم مربوط على `127.0.0.1:4180` فقط.

## معيار القبول المرئي

تظهر وحدة شؤون الطلاب وهيكلها الطبيعي، وتبقى قائمة السجلات دون بيانات مضللة، ويظهر تنبيه واضح: تمت محاكاة استنفاد قاعدة البيانات ولم يتم تعديل أي بيانات، مع زر «إعادة المحاولة».

لإيقاف البيئة: `Ctrl+C` في الطرفية التي تشغّل الأمر.
