# الوحدة 13 — تدقيق المخازن والمشتريات الشامل

التاريخ: 2026-08-29  
النطاق: المخزون + المشتريات والتوريدات  
حالة الوثيقة: `STAGING TECHNICAL CLOSURE — UAT PASSED; DELIVERY GATE PENDING`

## القرار التنفيذي

أزيلت مصادر النجاح الوهمي والتخزين المحلي، وربطت شاشات المخزون والمشتريات بمستند PostgreSQL مركزي ذي إصدار متفائل وسجل تدقيق. دورة PR → RFQ/عرض → PO → GRN → فاتورة مورد تعمل كسلسلة مستندية واحدة. أضيف ربط فعلي بخدمة دفتر الأستاذ الكانوني: الاستلام المقبول ينشئ قيد مخزون/GRNI، والفاتورة المعتمدة تنشئ قيد GRNI/AP، والحركة أو التسوية المعتمدة تنشئ قيدها المتوازن. إذا لم يكن مخطط ERP مثبتاً، يستمر الحفظ التشغيلي مع إرجاع حالة `not_provisioned` صريحة بدلاً من إنشاء نجاح محاسبي وهمي.

أُغلقت البوابة الفنية وطبقة Staging Database في 2026-08-30: طُبقت migrations المالية والمخزون، فُعّلت حماية السجل غير القابل للتعديل، ونجح UAT خادمي معزول يثبت إنشاء 4 قيود متوازنة و8 أسطر دفتر عام، وإعادة الترحيل دون تكرار، ثم تنظيف transaction بالكامل. لم يُدّعَ نشر Render أو UAT واجهة مصادق عليهما لعدم توفر جلسة/بيانات دخول اختبارية معتمدة في هذه المهمة.

الإغلاق التسليمي النهائي يتطلب نشر commit على بيئة التطبيق وتنفيذ UAT واجهة مصادق عليه؛ هذه بوابة نشر ومستخدم وليست فجوة في ربط المخزون بالحسابات.

## نطاق الشاشات

- لوحة المخزون، الأصناف، التصنيفات/العلامات/الوحدات، الموردون، المستودعات.
- الحركات، الجرد، تقارير التقييم وإعادة الطلب والدوران، الإعدادات، تقرير الجاهزية.
- لوحة المشتريات، طلبات الشراء، RFQ والعروض والترسية، أوامر الشراء، GRN والفحص، فواتير الموردين، التقارير، الإعدادات.

## الفجوات التي عولجت

1. استبدال local state/localStorage بمصدر PostgreSQL مركزي متعدد المدارس مع RLS.
2. إضافة optimistic concurrency ومنع ضياع تعديلات مستخدم آخر.
3. قفل المستندات المعتمدة/المصدرة/المستلمة/المدفوعة في الخادم.
4. تسجيل تغييرات snapshot وتصدير/طباعة التقارير في `audit_events` مع بصمات SHA-256.
5. إزالة البيانات الافتراضية المصطنعة من الأصناف والموردين والمستودعات والحركات والاستلام.
6. إتاحة المشتريات من داخل بوابة المخزون ومن مسار التطبيق المباشر.
7. إضافة إدخال عرض مورد حقيقي بأسعار كل بند، ثم ترسية مرتبطة بالمورد والعرض والمستودع.
8. تحديث رصيد الصنف بالكمية المقبولة فقط عند GRN، مع إنشاء رابط القيد الكانوني بعد الحفظ.
9. إضافة ترحيل فعلي للاستلام والفواتير والحركات وتسويات الجرد إلى دفتر الأستاذ المزدوج مع idempotency وسجل مصدر واضح.
10. استبدال شاشات شهادات 100% والمؤقتات بقائمة أدلة صريحة وحالات محجوبة بأمان.
