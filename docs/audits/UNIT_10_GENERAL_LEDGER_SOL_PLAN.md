## إصلاحات LUNA المسموح بها الآن

1. إزالة false-success copy من الواجهة.
2. تعطيل الأفعال التي قد تغيّر financial snapshot عندما لا توجد خدمة دفتر أستاذ كانونية معتمدة.
3. جعل فشل المصدر أو غياب tenant/school context واضحًا وقابلًا للتدقيق.
4. إبقاء الأرقام غير المتحققة غير متحققة، ومنع أي حساب من `gender` أو بيانات عرضية.
5. منع fallback المدرسي الثابت في validation.
6. إضافة اختبارات UI/contract لهذه الحواجز.

## خارج نطاق LUNA الحالي

- لا migration ولا SQL write جديد.
- لا تحديد account mapping أو سياسة الإقفال أو reversal أو balance model.
- لا إنشاء سند أو قيد أو أصل أو تحويل أو إقفال في UAT.

## بوابة قبول LUNA

- `npm run lint` و`npm run build`.
- الاختبارات المحاسبية الحالية كلها ناجحة.
- Browser UAT يبين أن القراءة المتاحة صريحة، وأن الأفعال المحاسبية غير المعتمدة disabled أو تعطي رسالة fail-closed دون نجاح.
- لا توجد رسالة «تم الترحيل/الإقفال بنجاح» بعد رفض العملية.
