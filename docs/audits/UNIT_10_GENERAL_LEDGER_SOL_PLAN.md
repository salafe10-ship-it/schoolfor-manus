# UNIT 10 — General Ledger — SOL Repair Plan

آخر تحديث: `2026-08-23`

## قاعدة الدورة

هذا الملف هو مرحلة `SOL` فقط. لا يُعد تقرير Manus إذنًا لإنشاء migration أو ترحيل مالي أو حذف أو تعديل بيانات UAT. يبدأ `LUNA` فقط في الإصلاحات البرمجية الآمنة التي لا تخمّن سياسة محاسبية.

## مصدر المراجعة

- تقرير Manus: `MANUS_—_FINAL_GENERAL_LEDGER_REVIEW (1).pdf`.
- UAT-B المرئي على `http://localhost:3001/`.
- المصدر الظاهر في UAT: `financial_portal_snapshots`، الإصدار `2`، و13 قيدًا و13 سند قبض و0 سند صرف.

## إصلاحات LUNA المسموح بها الآن

1. إزالة false-success copy من الواجهة.
2. تعطيل الأفعال التي قد تغيّر financial snapshot عندما لا توجد خدمة دفتر أستاذ كانونية معتمدة.
3. جعل فشل المصدر أو غياب tenant/school context واضحًا وقابلًا للتدقيق.
4. إبقاء الأرقام غير المتحققة غير متحققة، ومنع أي حساب من `gender` أو بيانات عرضية.
5. منع fallback المدرسي الثابت في validation.
6. إضافة اختبارات UI/contract لهذه الحواجز.

## خارج نطاق LUNA الحالي

- لا migration ولا SQL write جديد.
- لا تحديد account mapping أو سياسة الإقفال أو reversal أو balance model.
- لا إنشاء سند أو قيد أو أصل أو تحويل أو إقفال في UAT.

## بوابة قبول LUNA

- `npm run lint` و`npm run build`.
- الاختبارات المحاسبية الحالية كلها ناجحة.
- Browser UAT يبين أن القراءة المتاحة صريحة، وأن الأفعال المحاسبية غير المعتمدة disabled أو تعطي رسالة fail-closed دون نجاح.
- لا توجد رسالة «تم الترحيل/الإقفال بنجاح» بعد رفض العملية.

## القرار المرحلي

`SOL COMPLETE — LUNA AUTHORIZED FOR SAFE FAIL-CLOSED UI REPAIRS`

ولا يعني ذلك إغلاق الوحدة ماليًا؛ قرار الوحدة يبقى `NOT READY` حتى اعتماد عقد المحاسبة والمصدر الكانوني وتنفيذ UAT المالي الكامل.

## جولة SOL/LUNA الثانية — 2026-08-23

تمت مراجعة جميع عناصر التنقل الظاهرة في UAT-B: لوحة التحكم، شجرة الحسابات، مراكز التكلفة، القيود اليومية، سندات القبض، سندات الصرف، الحوالات البنكية، ذمم الطلاب، الموردون، الأصول الثابتة، التقارير المالية، السياسات، الإقفال، أدوات الحسبة، وإدارة الصلاحيات.

نتيجة المراجعة: لا أخطاء JavaScript ظهرت في الجولة، وكل شاشة أظهرت حالة المصدر المركزي. أُغلقت مسارات الكتابة المحلية المتبقية في قائمة القيود، شاشة القيد المفتوح، الحوالات البنكية، الأصول الثابتة، وإلغاء السندات. أصبحت الأفعال غير الكانونية disabled أو معنونة صراحة بأنها قراءة فقط، وأصبحت رسائل تصدير التقارير رسائل نسخة عرض غير معتمدة.

قرار SOL بعد الجولة: `COMPLETE — LUNA SAFE FAIL-CLOSED REPAIR VERIFIED`. لا يتغير قرار الجاهزية المالية: `NOT READY` حتى اعتماد كاتب دفتر الأستاذ وعقد الإقفال.

## جولة SOL الثالثة وخطة الإغلاق المستمر — 2026-08-24

### نطاق المراجعة

تراجع SOL كل شاشة ووظيفة حساسة في الوحدة: شجرة الحسابات وتدقيق IFRS، مراكز التكلفة، القيود اليومية، سندات القبض والصرف، الحوالات، ذمم الطلاب، الموردون، الأصول، التقارير، السياسات، الإقفال والصلاحيات. معيار القبول هو ألا تعرض واجهة UAT-B نتيجة مالية كـ«معتمدة/متوازنة/مغلقة» ما لم تكن مدعومة بكتابة كانونية موثقة.
