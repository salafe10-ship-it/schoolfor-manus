# STU-AFFAIRS-P1-006-52 — تقرير التنفيذ

## الحالة

CODE-LEVEL CLOSED — STUDENT DOCUMENTS METADATA CATEGORY/FORM STATE CONSISTENCY

## النطاق

اتساق نموذج metadata الحالي عند بدء مستند جديد أو تغيير الفئة أو اختيار مستند داخل الواجهة فقط.

## التغييرات

- بدء كل نموذج تسجيل جديد بقيم metadata فارغة وافتراضات canonical ثابتة، بدل حمل قيم من تسجيل سابق.
- تغيير فئة metadata يمسح رسائل الخطأ السابقة ويعيد حساب dirty state من القيم الحالية.
- تغيير المستند يمسح سبب الإجراء ونموذج الإصدار وسجل الوصول والاختيار السابق قبل بدء القراءة الجديدة.
- عدم إنشاء version أو metadata محلية وهمية؛ كل الحالة المعروضة بعد العمليات تأتي من canonical refresh.
- الحفاظ على submission guard وconflict handling وerror/empty distinction وaccessibility/focus.

## حدود العقد الحالي

لا توجد في العقد الحالي حقول خاصة بفئة معينة أو شاشة مستقلة لاختيار نسخة/تعديل metadata لنسخة محددة؛ لذلك لم تتم إضافة قواعد تصفير أو واجهات غير مثبتة.

## النطاق المستبعد

لا تغييرات في API أو backend أو الخدمات أو المستودعات أو قاعدة البيانات أو SQL أو RLS أو Storage أو المصادقة أو العزل أو ميزات الملفات الثنائية.
