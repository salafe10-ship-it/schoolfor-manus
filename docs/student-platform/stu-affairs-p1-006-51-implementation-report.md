# STU-AFFAIRS-P1-006-51 — تقرير التنفيذ

## الحالة

CODE-LEVEL CLOSED — DOCUMENT LIST/DETAIL SELECTION CONSISTENCY

## النطاق

اتساق اختيار المستند بين قائمة Student Documents وتفاصيله داخل الواجهة فقط.

## التغييرات

- مسح التفاصيل السابقة فور بدء تحميل مستند جديد.
- إضافة sequence guard يمنع استجابة طلب قديم من استبدال اختيار أحدث.
- إبقاء حالة تحميل التفاصيل واضحة، وعدم عرض detail قديم أثناء تحميل الجديد.
- مسح الاختيار والتفاصيل عند تغيّر أي filter أو عند اختفاء المستند من نتيجة canonical refresh.
- إعادة ضبط سجل الوصول وسبب الإجراء وإصدار النسخة عند إبطال الاختيار.
- عند فشل طلب التفاصيل تبقى الحالة Error ولا تتحول إلى Empty، مع الإبقاء على Retry القراءة فقط.
- تحديث مرجع الاختيار بعد canonical mutation refresh فقط.

## النطاق المستبعد

لا تغييرات في API أو backend أو الخدمات أو المستودعات أو قاعدة البيانات أو SQL أو RLS أو Storage أو المصادقة أو العزل أو الميزات الثنائية.
