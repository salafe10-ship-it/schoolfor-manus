# STU-AFFAIRS-P1-006-46 — تقرير التنفيذ

## الحالة

CODE-LEVEL CLOSED — METADATA FORM VALIDATION & DIRTY-STATE HARDENING

## النطاق

تم تحسين نموذج تسجيل بيانات مستند الطالب الحالي فقط. لم يكن في العقد الحالي مسار تعديل metadata مستقل، لذلك لم تتم إضافة API أو واجهة تعديل جديدة.

## سبب المعالجة

كان النموذج يحتاج إلى حماية صريحة من إرسال بيانات غير متغيرة أو غير صالحة، ومن فقدان تغييرات المستخدم عند الإغلاق أو الإلغاء دون تنبيه.

## التغييرات

- إضافة baseline موحد وحساب dirty state للنموذج.
- تعطيل الحفظ عند عدم وجود تغييرات.
- منع الطلب عند القيم غير الصالحة وفق العقد الحالي.
- تطبيع المسافات والأحرف الخاصة بنوع المحتوى قبل التحقق والإرسال.
- التحقق من الحقول المطلوبة، الأطوال، MIME type، الحجم، hash، التواريخ وترتيبها.
- إضافة تحذير واضح عند وجود تغييرات غير محفوظة، مع خيار متابعة التحرير أو الإغلاق دون حفظ.
- الحفاظ على البيانات عند فشل التعارض أو النتيجة غير المؤكدة.
- إزالة dirty state فقط بعد نجاح النتيجة الكانونية وتحديث القراءة الكانونية.

## النطاق المستبعد

لا توجد تغييرات في API أو الخادم أو الخدمات أو المستودعات أو قاعدة البيانات أو SQL أو RLS أو Storage أو المصادقة أو العزل أو رفع الملفات الثنائية.
