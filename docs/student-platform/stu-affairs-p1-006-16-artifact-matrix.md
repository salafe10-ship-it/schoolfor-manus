# STU-AFFAIRS-P1-006-16 — Artifact Matrix

## Classification key

- **CANONICAL** — source and delivery contract already proven.
- **DESIGN READY** — contract defined here but requires owner/security approval.
- **BROWSER PRESENTATION** — local view print only; never official.
- **BLOCKED** — dependency or owner decision prevents a safe contract.

| Artifact | Status | Source of truth | Generation | Format | Delivery | Permission | Scope | Retention | Audit classification |
|---|---|---|---|---|---|---|---|---|---|
| Student Data Export | CANONICAL | Canonical Student read repository | Server, bounded ≤5,000 | XLSX | Direct download | `Student.Export` | Trusted tenant/school/branch; permitted filters | UNDECIDED | Accepted/rejected/failed/generated/delivered already designed |
| Official Student List Report | DESIGN READY | Canonical Student read repository | Server artifact; mode UNDECIDED | PDF/printable format UNDECIDED | Download or controlled print | Proposed distinct report permission; name UNDECIDED | Trusted tenant/school/branch | UNDECIDED | Required before implementation |
| Browser Print | BROWSER PRESENTATION | Current rendered page | Browser `window.print()` | Printer output | Browser print dialog | Existing outer UI visibility only; not a certified report permission | Current UI state; not authority | None | No server report audit |
| Enrollment Certificate | DESIGN READY | Enrollment + approved academic context | Server issuance | PDF/secure format UNDECIDED | Download/print/verification URL UNDECIDED | Proposed issuance permission; name UNDECIDED | Trusted student object and tenant scope | UNDECIDED | Required before implementation |
| Student ID Card | DESIGN READY | Canonical Student identity + school identity | Server issuance | Card PDF/digital format UNDECIDED | Download/print/digital card UNDECIDED | Proposed issuance permission; name UNDECIDED | Trusted student and school/branch scope | UNDECIDED | Required before implementation |
| Academic Report / Transcript | BLOCKED | Authoritative Results/GPA source not proven | UNDECIDED | UNDECIDED | UNDECIDED | UNDECIDED | Trusted student + academic context | UNDECIDED | Blocked by Results/GPA owner decision |
| Student Financial Statement | BLOCKED | Finance domain | Finance-owned artifact | UNDECIDED | UNDECIDED | Finance-approved permission | Finance trusted scope | UNDECIDED | Blocked by Finance owner/security decision |

## Artifact identity fields

Every official artifact should have these design fields before implementation:

| Field | Decision |
|---|---|
| Artifact type | Required; one of the approved artifact classes above |
| Report/artifact code | UNDECIDED until Owner approval |
| Version | Required and immutable per generated artifact |
| Source of truth | Required; no browser array or fallback authority |
| Request/correlation ID | Required from trusted request context |
| Tenant/school/branch scope | Required from trusted context |
| Generation time | Server UTC time |
| Generated by | Trusted authenticated identity |
| Delivery result | Separate from generation result |
| Retention | UNDECIDED until policy approval |

## Decision boundaries

- Student Data Export remains separate from Official Student List Report.
- Browser Print remains separate from every official artifact.
- ID Card is not a Certificate.
- Enrollment Certificate is not a Graduation Certificate.
- Academic Transcript cannot be built from unapproved Results/GPA data.
- Financial Statement cannot be calculated by Student Affairs.
