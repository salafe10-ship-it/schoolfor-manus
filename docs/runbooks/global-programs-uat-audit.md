# مراجعة قبول الوحدات المؤسسية — UAT-B

تاريخ المراجعة: 2026-08-24

## نطاق المراجعة

تم جرد الوحدات الرئيسية التي تظهر في بوابة المدرسة، مع فحص مصادر البيانات، الأزرار العامة، حالات الفراغ، التصدير والطباعة، وحماية العمليات المدمرة. المراجعة لا تعتبر زرًا ناجحًا إذا عرض رسالة نجاح دون حفظ مركزي قابل للإثبات.

## نتيجة الوحدات العشر

| الوحدة | القراءة/العرض | الحفظ المركزي | حالة الاختبار |
|---|---|---|---|
| شؤون الطلاب | مرتبط بمسارات API واختبارات تعاقدية | متاح للمسارات المعتمدة | جاهز لاختبار قبول إضافي |
| الشؤون الأكاديمية | الشاشة والخوارزميات موجودة | المواد والجدول المحليان يحتاجان مستودعًا أكاديميًا مركزيًا | غير مغلق |
| الامتحانات والنتائج | وحدة واسعة وبها مسارات API وطباعة | مساراتها الأساسية مغطاة باختبارات | جاهز للمراجعة التشغيلية التفصيلية |
| الموارد البشرية | تعمل بوضع الإيقاف الآمن عند غياب المصدر | غير مهيأ في بيئة UAT الحالية | غير مغلق |
| الحسابات العامة | دفتر الأستاذ الكانوني والتقارير متصلة | 23 قيدًا و46 سطر أستاذ، مدين = دائن 19,200 د.ل | جاهز للإغلاق المالي |
| المخازن والمستودعات | التبويبات التسعة فتحت دون أخطاء في المتصفح | CRUD يمر عبر InventoryRepository؛ الاستيراد العام متوقف بوضوح | جاهز للقراءة، الحفظ حسب المصدر |
| المشتريات والتوريدات | المسارات والشاشات موجودة | المستودع المحلي محمي في الوضع الكانوني؛ دفعات المورد أصبحت تحفظ فقط عندما يكون المصدر مسموحًا | غير مغلق حتى ربط مصدر مركزي |
| الخزينة والبنوك | واجهة وخدمات TreasuryRepository/Engine موجودة | مسارات الحسابات والتحويلات مربوطة بالمستودعات | جاهز لاختبار قبول إضافي |
| المكتبة | الكتالوج يقرأ عبر LibraryRepository | إضافة الكتاب تمر عبر المصدر المركزي؛ الإعارة والغرامات تنتظر جداولها المركزية | غير مغلق |
| الزي المدرسي | الواجهة وخدمات SQL موجودة | يحتاج تدقيق تشغيل مركزي لكل حركة | غير مغلق |

## إصلاحات هذه الجولة

- تصحيح تجميع الميزانية في التقارير عندما تكون شجرة الحسابات بلا مستويات أب محفوظة؛ أصبح فارق الميزانية `0.00 د.ل`.
- منع رسالة النجاح الوهمية في زر الحفظ العام للمخزون وفي استيراد المخزون غير المهيأ.
- تمرير معرف المدرسة الحقيقي إلى مستودع المخزون بدل الاعتماد الثابت على `school_1`.
- ربط قراءة وإضافة كتب المكتبة بـ `LibraryRepository`، وإزالة الغرامة الثابتة `15.00 ريال`.
- منع إغلاق الإعارة أو ترحيل الغرامة محليًا دون مسار مركزي.
- إضافة حفظ سجل دفعات المورد إلى مستودع المشتريات عندما يكون المصدر المسموح متاحًا، مع رسالة توقف واضحة في الوضع الكانوني غير الموصول.
- تحويل تصدير فواتير المشتريات من رسالة فقط إلى ملف CSV فعلي.

## ضوابط الاختبار

- تم فتح تبويبات المخزون التسعة من المتصفح، ولم يظهر خطأ في فحص النص الظاهر.
- تم اختبار أزرار Excel وPDF في التقارير المالية؛ استجابت دون أخطاء JavaScript. عدم ظهور نافذة طباعة فعلية في DOM لا يساوي إثباتًا بطباعة ورقية.
- لم تُستخدم أزرار الحذف أو الاعتماد أو الاستيراد على بيانات حقيقية، حتى لا تتغير القيود الموجودة.
- شاشة إدارة الصلاحيات أعادت `403_FORBIDDEN` لدور مدير المدرسة؛ لا يتم تجاوز ذلك برمجيًا.

## قرار الإغلاق

وحدة الحسابات العامة قابلة للإغلاق المالي بعد نجاح الاختبارات الآلية والبصرية الموضحة في دليلها. أما إغلاق الوحدات العشر كحزمة ERP كاملة فيتطلب أولًا توفير المستودعات المركزية الأكاديمية والموارد البشرية والمكتبة والمشتريات/المخزون والزي، ثم إعادة اختبار الحفظ والترحيل والقيود الناتجة.
